# 🧘 MindfulJournal AI 
### *Your Agentic Personal Wellness Ecosystem*

MindfulJournal AI is a professional-grade wellness assistant built to bridge the gap between daily habit tracking and emotional intelligence. By leveraging a **Multi-Agent Architecture** and **Azure AI**, it provides real-time, data-driven support for mental well-being.

## ✨ Key Features
* **Reflection Agent:** Uses **Microsoft Azure AI Language Services** for high-precision sentiment analysis, identifying emotional nuances that basic tools miss.
* **Motivation Agent:** Provides dynamic, context-aware encouragement and actionable insights based on your journaling trends.
* **Dynamic Growth Dashboard:** A live-updating summary that tracks journaling streaks and emotional baselines in real-time.
* **Integrated Habit Tracker:** Connects physical habits (movement, hydration) to mental states to spot productivity patterns.

## 🛠️ The Tech Stack
* **Frontend:** Streamlit (Modern, Responsive UI)
* **Intelligence:** Azure AI Language Services (Sentiment Analysis)
* **Logic:** Python-based Multi-Agent System
* **Storage:** Local CSV History (Privacy-First Approach)

## 🚀 Why Azure?
I chose **Azure AI Language Services** over general LLMs to ensure deterministic, reliable, and supportive responses. This ensures the app adheres to the highest standards of accuracy for mental health support.
